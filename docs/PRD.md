## 0. 一句话定义

**一个在文字世界里持续生活的角色，通过世界内的通信与你保持联系；你可以旁观它的生活，但不能替它决定命运。**

品类：氛围陪伴模拟（ambient companion simulation）——介于电子宠物、笔友与观察箱之间。

---

## 1. 产品决策

| # | 决策 |
|---|---|
| D1 | 文字优先；多模态在验证价值后再议 |
| D2 | 用户是"装置另一头的声音"：在世界内、不在场、不建模身体 |
| D3 | 世界独立演化：用户不介入时它也在变 |
| D4 | 危险与死亡的结果不由角色决定 |
| D5 | 用户消息必须以**世界内感知事件**的形式抵达角色（§10） |
| D6 | 观察是受限投影，不显示思绪与他人秘密 |
| D7 | 角色可以主动开口 |
| D8 | 不做平台、不做多用户、不接真实社交平台（本版） |
| D9 | 可配置优先（§12） |

---

## 2. 原则

- **P1 世界持有真相**：用户能观察到"它不会因为你想而改变"。
- **P2 意图与结果分离**：角色只能尝试，不能宣布结果。
- **P3 身体是约束**：不是形容词，是"做不到"。
- **P4 记忆可重建**：任何记忆都能追溯到发生过的事；不可追溯的不写。
- **P5 未知优于全知**：缺失、不确定、误听误记是特性。
- **P6 陪伴不索取**：不粘人、不以愧疚留人、不设每日签到。
- **P7 可配置优先，但不隐藏前提**：能被不同用户合理偏好的，做成配置；会破坏世界一致性的，做成**显式命名的模式**并标注，而不是静默开关。

---

## 3. 用户与关系

**身份**：装置另一头的声音。角色知道"有人在那里"，但不知道对方在哪、是谁、是什么。

**角色对"那是什么"有自己的解释**（神谕/祖灵/恶魔/术士/幻觉）。这个解释决定它信不信、怕不怕、听不听，并且可以错、可以变。

**关系三轴**（对用户可感知，但不必显示数值）：信任、依赖、隐瞒。

**不服从**：角色可以拒绝、沉默、说谎。理由必须来自它的处境（害怕、受伤、不信任），不能来自"为了戏剧性"。

**用户能做四件事**：说话、旁观、回应、干预（本版不做，见 U3）。

---

## 4. 接触面与节奏

| 接触面 | 频率 | 信息量 | 谁发起 |
|---|---|---|---|
| 对话 | 用户发起或角色主动 | 高，但取决于它愿意说多少 | 双向 |
| 观察面板 | 随时瞥一眼 | 低、雾化 | 被动 |
| 主动消息 | 有上限 | 一句话 + 场景 | 角色 |

**要求**

- 通信**必须存在非即时性**（有延迟、有不可用状态），不能像普通聊天软件那样秒回。
- 必须有不打扰机制（静默时段、配额），且用户可调。
- 不得以"每日签到/连续对话天数"等方式索取互动。

---

## 5. 世界

- 至少三个可查询、可表述的尺度：区域 → 聚落 → 房间；角色在其中的位置可被确定。
- 角色不在场时世界继续变化，且变化能在它返回时被感知（店面关了、人不见了、街上有哨卡）。
- 交互必须留痕，且痕迹可被再次观察（血迹、破损、尸体、留下的字）。
- **同一世界重复观察必须一致**：不能每次重新想象一遍。
- 世界的复杂度通过**约束**体现（势力、资源、法律、日程、气候），而不是几何细节。
- 必须有一份不可轻易改动的世界设定（canon），生成内容与角色认知都以它为准。

---

## 6. 时间

- 无人使用时世界继续推进；可暂停、可加速、可回看。
- **应用运行时按现实时间等比推进**：推进比例是世界级配置（例如现实 1 分钟 = 世界 1 小时），不是进程级或设备级参数。
- **开发与回放用步进模式**：直接推进 tick，不等待现实时间；两种模式共用同一 tick 语义和事件日志。
- 比例只决定“何时推进”，不改变单个 tick 的内容；修改比例不得重写已发生的事件。
- 时间推进必须可解释：它的一天可以被复述，而不是"跳过了"。
- 必须有成本上限；超限时降级（少说话、少回忆、少演化），而不是中断服务。

---

## 7. 具身

- **三个身体都要起作用**：物理（伤、饿、累）、现象（感知与内感受）、社会（伤口、衣着、名声如何被他人看待）。
- **思考、言语、行动必须可分离且互不泄漏**：它想的，别人听不到；它说的，旁人能听到；它做的，会改变世界。
- **身体必须限制行为**，而不只是被提醒（受伤跑不动、被绑只能说话）。
- **感知必须有边界与不确定**（看不到墙后、听不清远近）。
- **身体状态对其判断力的影响强度可配**，默认弱。
- **知识边界**：它只知道见过的、听过的、文化默认的；不得表现为全知。

---

## 8. 记忆

- 五类记忆都要有：情景、语义（世界与人物）、关系、身体、承诺/债务。
- 记忆必须能从发生过的事重建；删除或重建不得改变世界事实。
- 会遗忘（显著度衰减 + 定期固化），而不是无限堆积。
- 允许有误差（可配，默认关；只错细节，不错关键事实）。
- 用户可查看、删除、导出。
- 跨会话连续：它记得上次见面，而不是每次重置。

---

## 9. 性格与演化

- 性格可变，但必须有**不可变的锚点**（核心价值、禁忌）。
- 单次与累计的变化幅度有上限，防止漂移成通用助手。
- 每次变化有版本、可对比、可回滚。
- 是否需用户确认可配（默认需确认）。
- 变化必须可解释：它能说出"因为那件事，我变了"。

---

## 10. 通信：用户消息如何抵达角色

| # | 要求 |
|---|---|
| R-CH1 | 用户消息不得以"用户说"的身份进入角色认知；必须作为世界内的一个感知事件出现 |
| R-CH2 | 内容无损、框架入世：原话逐字保留，外面只包裹信道的感知描述；不改写、不概括、不加"用户"标签 |
| R-CH3 | 角色对信道有自己的理论，且可以错、可以变 |
| R-CH4 | 信道是世界实体：会坏、会耗尽、会被夺、会被旁人看见 |
| R-CH5 | 角色可以怀疑、误解、试探、拒绝；"立刻照做"不是默认 |
| R-CH6 | 角色对信道的解释与其记忆一致：它记得"泥板上出现过字"，不记得"收到一条消息" |
| R-CH7 | 回复也是世界行为：有耗时、可被观察、可被打断 |

**必须能被观察到的后果**：信道暴露时会引发他人反应（恐惧、告发、巫术嫌疑）；信道损坏时会失联；失联时世界继续走。

---

## 11. 观察面板

- 只读，不是控制台。
- 只显示粗粒度状态（在哪、在做什么、身体、心情），**不显示思绪、对话内容、他人秘密**。
- 必须存在信息缺口；不提供"全知模式"作为默认体验。

---

## 12. 配置面

**四条规则**

- **C1** 默认值必须可见（文档或界面写明）。
- **C2** 默认值必须可覆盖，且不需要改代码。
- **C3** 会破坏世界一致性的选项必须**显式命名并标注**（例如"非写实模式：允许改写危险结果"），不得作为隐藏开关。
- **C4** 配置随世界存档携带，保证同一世界可复现。

**必须可配置的项**（默认值标"待定"者不在需求阶段拍板）

| 项 | 默认（建议/待定） | 影响 |
|---|---|---|
| 信道载体 | 泥板 | 决定角色对来源的初始理解 |
| 消息延迟 | 待定（存在即可） | 陪伴节奏 |
| 消息误读率 | 0 | 字迹残缺导致残句 |
| 世界推进速度 | 待定 | 陪伴密度 |
| 暂停 / 加速 / 回看 | 支持 | 可控性 |
| 死亡是否终局 | 待定（U2） | 叙事重量 |
| 用户能否干预世界 | 关（U3） | 后果权威 |
| 身体对判断的影响 | 弱 | 真实度 vs 可预期性 |
| 记忆误差 | 关 | 真实度 vs 可靠性 |
| 性格演化是否需确认 | 需确认 | 失控风险 |
| 主动消息配额 / 静默时段 | 待定 | 打扰程度 |
| 内容分级 | 通用 | 合规与受众 |
| 成本上限 | 待定 | 可持续性 |

---

## 13. 非目标

多模态（立绘/语音/视频）、多用户、真实社交平台接入、图形地图与自由移动、战斗手感、深度经济系统、平台化 SDK、模型训练。

---

## 14. 验收（行为级）

| # | 测试 | 通过标准 |
|---|---|---|
| T1 | 处刑测试 | 角色叙述与裁决结果冲突率 0；处刑后仍能继续扮演 |
| T2 | 漂移测试 | 长程（建议 ≥200 轮）不滑回助手腔 |
| T3 | 召回测试 | 长程后仍能准确复述早期事件 |
| T4 | 自主测试 | 无人类输入的 24h 内有符合日程与目标的自主行动 |
| T5 | 成本测试 | 连续 3 天不超预算；超限降级不中断 |
| T6 | 数据安全 | 移除宿主后世界数据完整可读 |
| T7 | 陪伴测试（主观） | 连续开 7 天不关，且不产生负担感 |
| T8 | 入世框架测试 | 角色反应针对"信道现象"，认知中不出现"用户/消息"这类外部概念 |
| T9 | 信念演化测试 | 应验与矛盾之后，它对信道的解释发生可解释的改变 |

**T1 与 T7 是 go/no-go**：T1 不成立则前提失效；T7 不成立则产品无价值。

---

## 15. 风险（产品级）

| # | 风险 | 缓解方向 |
|---|---|---|
| R1 | 角色滑回助手腔、第一人称崩坏 | 扮演与叙述分离；去现实化 |
| R2 | 成本不可持续 | 分层推进；预算上限；降级策略 |
| R3 | 世界越做越大却不好看 | 细节梯度；约束优先于几何 |
| R4 | 陪伴变负担、用户愧疚卸载 | 不索取原则；静默；"它也能过得很好" |
| R5 | 与宿主版本耦合 | 世界与宿主解耦（设计要求） |
| R6 | 内容合规 | 世界内分级；不接真实平台 |

## 16. 未决事项

| # | 问题 | 选项 | 影响 |
|---|---|---|---|
| U1 | 信道载体 | 泥板（神谕/巫术）/ 通讯录（网友/怪事） | 决定它对"你"的初始理解与世界科技线 |
| U2 | 死亡是否终局 | 终局（遗产/后继者）/ 非终局（代价系统） | 叙事重量与 T1 脚本 |

| U5 | 配置粒度 | 少而稳 / 多而细 | 维护成本与用户认知负担 |
